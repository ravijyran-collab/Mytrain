# Mytrain Android demo preview

Internal test preview using fictional trains only. No live railway data.

[Download APK](preview/mytrain-native-preview.apk?raw=true)

Android 7 or later. Native Android controls; this is the standalone Java preview, not the Expo APK. Built and signature/alignment checked; physical-device launch remains unverified. No Internet permission.

Source and local build instructions: [native preview README](apps/native-preview/README.md). No signing key is published. This preview branch preserves main and does not publish to Google Play.
